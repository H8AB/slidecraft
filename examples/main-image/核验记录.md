# 0.1.1 案例核验

- 01-created.pptx 从 deck.json 与商品图片新建。02-before.pptx 是为测试制作的白底运营草稿。03-optimized.pptx 由 apply 读取 02-before.pptx 和 plan.json 生成。
- 用 LibreOffice 加载中文字体，将三个文件的 15 页渲染成图后逐页查看。图片对照、柱图标签、表格和分工说明均可见。
- 对原稿与优化稿的 PPTX 包逐部件比较，变化限于 5 个页面 XML。页内文字逐项一致，备注、图片、图表、图表工作簿及关系文件字节相同。第 3 页含原生柱图及嵌入的 XLSX，第 4 页含三行原生表格。
- 核对算式：720 / 20,000 = 3.6%，900 / 20,000 = 4.5%，差 0.9 个百分点，相对差异为 25%。36 / 720 和 45 / 900 均为 5.0%。
- 在 Chrome 中直接载入电商草稿与内置方案并下载优化版；另从普通大纲下载新稿、从完整案例下载新稿、导入现有文件、下载对象清单、导入改版方案并下载优化副本。进一步读取下载文件验证原生图表、文字和表格。
- 分别解压平台 ZIP，运行其内置的免 npm 安装 Node 工具完成制作与优化。未在 Claude 和 WorkBuddy 的真实账户完成上传、安装和调用测试。工具依赖宿主能力，市场上架还需对应流程。
