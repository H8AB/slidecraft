# Use a web assistant with the offline editor

[English user guide](../docs/guide.md) · [简体中文](AI网页使用说明.md)

**Create a deck.** Attach your brief and the [file format reference](../skills/slidecraft/references/formats.md). Ask for the following:

> Produce a valid Slidecraft deck.json for the audience and decision in my brief. Use one supported slide kind per page. Preserve the data units and time window. Use fractional values for percentages and set the chart number format. Include the image filenames I supply.

Paste the JSON into **Create a deck**, select the named images and choose **Download editable PPTX**.

**Restyle a deck.** Import your presentation under **Restyle a deck** and download the inventory. Share the inventory and relevant slide screenshots with the assistant.

> Use the Slidecraft format reference to return a plan.json for this specific file. Copy the source fingerprint and actual object IDs from the inventory. Prioritize the visual changes that will help this audience read the slide. Preserve text, chart data, notes and slide order.

Select **Import a JSON plan**, then **Apply plan and download a copy**. Review the rendered pages in your presentation app. The local editor handles the files on your device. Any material you send to a separate web assistant is shared with that service.
