# 在普通 AI 网页里制作或优化 PPT

支持自定义技能的网页可直接导入平台包。在只支持聊天与附件的网页中，打开配套的 slidecraft.html。在本地网页中下载 PPTX；AI 聊天用来判断设计和撰写大纲。下面的两条提示可复制，并随附技能中的 references/formats.md 和 references/design.md。

## 从材料制作
请用随附 Slidecraft 文件接口，根据我的材料制作演示大纲，返回有效的 deck.json。交代受众、要做的决策、每页标题和支持证据。图表保留可编辑数据，百分数使用小数和 numberFormat，来源写页脚或备注。材料没有提供的数字不要补造。若需要对照图，我会补充对应 asset 图片。我的材料如下……

在本地网页的“制作新稿”粘贴大纲，选择它引用的图片，下载 PPTX。也可直接写简短大纲，或载入电商案例。

## 优化已有文件
在本地网页导入原 PPTX，下载对象清单。把清单、原稿渲染图和接口说明提供给 AI，仅分享你有意发送的信息。

请按 Slidecraft 文件接口分析清单与渲染图，说明最影响阅读的问题，给出 plan.json。source 必须来自这份清单，页码和对象编号必须匹配。请保留原文、页序、图表及备注；每条改动落实到具体对象、颜色、字号或位置。复杂页保留原状并列出。我的受众与风格要求是……

把结果粘贴到本地网页的“排版方案”，点击应用并下载副本，再用 PowerPoint 或其他兼容软件查看。工具不需要 API key，网页本身在浏览器里读写文件；聊天平台按自身方式处理你上传的附件。
