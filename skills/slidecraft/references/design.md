# Visual design decisions

[简体中文](design.zh-CN.md)

Base information density and type size on how the audience will read the deck. Projected slides need a clear focal point. A document for later reference can carry more detail. Respect the supplied brand, master, assets and aspect ratio.

- For product comparisons, align the images and captions. Match scale and angle when possible so viewers can judge the difference under discussion.
- For data, verify the numerator, denominator, time window and unit before choosing a chart. Start bars at zero when comparing magnitudes. Distinguish percentage points from relative percent change.
- Anchor a takeaway in specific evidence. Where the source only describes a topic, a descriptive heading is sufficient.
- Put ownership, action and timing on the same reading path. Preserve editable objects and source details that the presenter may need to update.
- Check rendered text, chart axes, image crops and label alignment. Align items that play the same role. Preserve deliberate variations in emphasis.
