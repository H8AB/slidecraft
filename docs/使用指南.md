# Slidecraft 使用指南

Slidecraft 有两种入口。下载离线网页即可在浏览器中制作或改版。安装技能后，可以用自然语言让智能体读取材料、设计版式和交付文件。以下步骤均可用仓库里的模拟电商案例练习。

## 在浏览器体验两种工作方式

1. 下载 [slidecraft.html](../downloads/slidecraft.html?raw=true)。如果 GitHub 展示文件页面，点击 **Download raw file**。在桌面浏览器打开下载的 HTML。
2. 在「制作新稿」点击「载入电商案例」，再点「下载可编辑 PPTX」。打开下载的五页演示稿，第 3 页是带数据的柱图，第 4 页是 PowerPoint 表格。
3. 切到「优化已有 PPT」，点击「试用电商改版案例」，再点「应用方案并下载副本」。网页已内置该案例的原稿和排版方案。打开副本，对照[原稿与改版效果](../examples/main-image/comparison.jpg)。
4. 换成自己的材料时，首行写封面标题，正文用 `## 页标题` 分页，每页写一至三行 `项目｜说明`。需要图表、表格或图片时，可直接编辑 JSON 大纲。选取大纲引用的本地图片后生成文件。网页在浏览器中处理文件，无需 API 密钥。

## 在智能体中安装

- **Codex**　下载 [通用技能 ZIP](../downloads/slidecraft-agent.zip?raw=true)，解压后将整个 slidecraft 文件夹放进项目的 `.agents/skills/`。从项目中调用 `$slidecraft`。
- **Claude Code**　下载同一 ZIP，将其中的 slidecraft 文件夹放进项目的 `.claude/skills/`。打开项目会话，调用 `/slidecraft`。
- **Claude 网页**　在支持自定义技能的账号中，通过 Customize → Skills 上传通用 ZIP 并启用。该会话需要具备生成文件的能力才能直接交付 PPTX。
- **WorkBuddy**　下载 [WorkBuddy 技能包](../downloads/slidecraft-workbuddy.zip?raw=true)，在技能管理中添加本地技能包，再在会话中选择 Slidecraft。该包包含 WorkBuddy 的展示信息。
- **其他 AI 网页**　可以把[提示词和操作步骤](../web/AI网页使用说明.md)与[大纲和改版方案格式](../skills/slidecraft/references/formats.md)发给支持附件的 AI，得到 deck.json 或 plan.json 后在本地网页应用。

解压后的技能入口应为 `slidecraft/SKILL.md`。随包执行器需要 Node.js 18+，依赖已打入包内。没有 Node.js 时可直接使用 HTML 入口。网页功能已在桌面 Chrome 中测试。

## 两条可复制的请求

**用我的材料制作演示稿**

> 请用 Slidecraft 把附件中的搜索主图 A/B 测试简报制作成 5 页可编辑 PPT，供商品运营周会使用。展示两版主图、点击率、下单表现和下周安排。保留数据单位、归因窗口及图片来源，检查所有页面后返回 PPTX。

试用时附上[业务简报](../examples/main-image/brief.md)和[两版主图](../examples/main-image/assets/main-image-pair.jpg)。

**优化我已有的演示稿**

> 请用 Slidecraft 优化附件中的 PPT。让观众先看懂点击率差异，再看到原始图表和订单数据。保留原文、页序、数据与备注，以新文件交付，并附关键页前后对照。

试用时附上[待优化原稿](../examples/main-image/02-before.pptx?raw=true)。其他 PPT 请使用它们各自的排版方案。每个方案会核对原文件指纹，换了输入文件就需重新读取对象清单。

## 命令行复现案例

从 GitHub 下载项目源码并解压，在项目根目录执行。下面三个输出路径请使用新文件名。

```sh
npm ci --prefix skills/slidecraft
node skills/slidecraft/scripts/slidecraft.cjs create examples/main-image/deck.json new.pptx
node skills/slidecraft/scripts/slidecraft.cjs inspect examples/main-image/02-before.pptx > inventory.json
node skills/slidecraft/scripts/slidecraft.cjs apply examples/main-image/02-before.pptx examples/main-image/plan.json polished.pptx
```

只有技能 ZIP 时，使用包内的 `scripts/run.cjs` 执行相同的子命令。网页端、命令行和智能体共享大纲及改版方案格式。

## 使用自己的旧稿

在本地网页选择 PPTX 并下载对象清单。向智能体提供清单、需修改页的截图和设计要求，取得 plan.json，再点「导入方案 JSON」和「应用方案并下载副本」。默认的短标题加粗只是一项快捷操作，完整改版需要结合页面画面设计。带动画、部分嵌入对象或数字签名的稿件可能只支持诊断。

最终请用实际演示设备打开 PPTX，检查中文字体替换、文字换行、图表标签及原生图表的数据编辑。示例采用苹方，跨系统制作新稿时可在大纲的 font 中选择本机中文字体。已验证的范围见[案例核验记录](../examples/main-image/核验记录.md)。
